# Установить Chatkeeper

Проведи установку по сценарию `${CLAUDE_PLUGIN_ROOT}/install.md`. **Прочитай его целиком
до первого действия** и дальше следуй ему по шагам, не пропуская ни одного.

Три вещи, которые нарушать нельзя:

1. **Первый шаг - честное предупреждение и явное согласие.** Без ответа человека
   дальше не идёшь. Это шаг 0 сценария.
2. **Вопросы задаёт программа, а не ты.** Порядок: `chatkeeper setup wizard` показывает
   следующий незаданный вопрос, ты задаёшь его человеку своими словами,
   `chatkeeper setup answer <имя> <ответ>` записывает ответ. Так до `ГОТОВО`.
   Своих вопросов не выдумывай, чужие не пропускай.
3. **Команды выполняешь ты, человеку их не показываешь.** Он не программист:
   терминал не открывает, файлы не правит, текст ошибок не читает.
   Говори обычными словами, ошибки переводи на человеческий.

Если команда `chatkeeper` ещё не работает - так и должно быть в самом начале:
рабочее окружение создаётся первым шагом сценария, командой
`python "${CLAUDE_PLUGIN_ROOT}/scripts/setup.py" bootstrap` (на macOS `python3`).
До этого момента ни одна команда `chatkeeper` работать не будет, и это не поломка.
