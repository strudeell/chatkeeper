# Установка Chatkeeper

Инструкция для Claude. Человек, который это ставит, **не программист**: терминал
не открывает, файлы не правит, ошибки не читает. Только отвечает словами в чат
и нажимает кнопки в телеграме.

Все команды выполняешь ты. Показывать их человеку не нужно - от этого он теряется.
Говори обычными словами: «готовлю рабочую папку», а не «создаю virtualenv».

**Важно про порядок.** Бот теперь не только присылает сводку, но и приносит сообщения.
Поэтому он заводится раньше всего остального, а не в конце.

---

## Как задавать вопросы

Вопросы установки заданы не в этом тексте, а в самой программе, и она помнит,
на какие уже отвечено. Порядок такой:

```
chatkeeper setup wizard              показывает следующий незаданный вопрос
chatkeeper setup answer <имя> <ответ>  записывает ответ
```

Вызывай `wizard`, задавай человеку показанный вопрос **своими словами**, записывай
ответ, вызывай снова - пока не ответит `ГОТОВО`. Ответ `ОТКАЗ` означает, что человек
не разрешил разбор переписки: тогда установка прекращается.

Так сделано намеренно. Раньше вопросы жили только в этом документе, и однажды сессия
провела «установку», не задав ни одного вопроса: документ никто не проверял.
Теперь незаконченная установка физически не пускает разбор.

## Шаг 0. Честное предупреждение (обязательно, до всего остального)

Это вопрос `consent` из мастера. Скажи своими словами и **дождись явного согласия**:

> Chatkeeper будет читать твою личную переписку в телеграме и отдавать её на разбор
> искусственному интеллекту. Три вещи, которые нужно знать до установки.
>
> Первое: содержимое переписки уходит в языковую модель. Иначе система работать
> не может - разбирать договорённости больше нечем. Правила Telegram разрешают это
> при твоём явном согласии, поэтому я и спрашиваю прямо.
>
> Второе: твои собеседники согласия не давали и о системе не узнают. Технически
> они ничего не увидят: бот только читает, никогда не пишет и не помечает сообщения
> прочитанными. Но решение отдавать чужие слова на разбор - твоё.
>
> Третье: переписка остаётся в истории Claude Code у тебя на компьютере. Рабочий файл
> удаляется сразу, а копия в истории сессии живёт, пока её не удалить. Команду покажу
> в конце.
>
> Что сделано, чтобы риска было меньше: система умеет только читать - отправлять
> сообщения от твоего имени она не может физически; разбор идёт раз в сутки;
> любой чат можно закрыть наглухо, и он не будет читаться никогда.
>
> Отдельно: рабочие группы система не читает. Только личные диалоги.
>
> Продолжаем?

Если человек отказывается или сомневается - **останови установку**. Не уговаривай.

## Шаг 1. Рабочее окружение (человека не касается)

Одна команда, запускается любым системным python:

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/setup.py" bootstrap
```

На macOS вместо `python` может понадобиться `python3`.

Она создаёт окружение в `${CLAUDE_PLUGIN_DATA}` - в папке, которая переживает
обновления плагина, - и ставит туда нужные библиотеки.

Если python в системе нет вовсе:
- Windows: `winget install --id=astral-sh.uv -e`
- macOS: `brew install uv`

затем `uv python install` и повтори команду выше через `uv run python`.

Дальше всё делается командой `chatkeeper` - она появляется в PATH вместе с плагином.
Проверь: `chatkeeper setup check`.

Человеку в это время скажи одну фразу: «Готовлю рабочую папку, полминуты».

## Шаг 2. Бот

Скажи человеку:

> Заведём бота. Он будет и приносить сообщения, и присылать сводку по утрам.
> В телеграме найди `@BotFather`, напиши `/newbot`, придумай имя (например `Chatkeeper`)
> и адрес - любой свободный, обязательно заканчивается на `bot`.
> В ответ придёт длинная строка с двоеточием посередине - пришли её мне.

Получив токен:

1. `chatkeeper setup env-set TELEGRAM_BOT_TOKEN <токен>`
2. Попроси нажать **Start** в чате с новым ботом: без этого Telegram запрещает боту
   писать первым.
3. `chatkeeper setup bot-owner` - определит, кому слать сводку.
   Если скрипт говорит, что сообщений нет - попроси нажать Start ещё раз и повтори.

## Шаг 3. Включить боту режим помощника

Без этого бота нельзя будет подключить к личным чатам: он просто не появится в списке.

Скажи человеку:

> Вернись в `@BotFather`, напиши `/mybots`, выбери нашего бота, нажми **Bot Settings**,
> потом **Secretary Mode** и включи его. Скажи, когда готово.

Проверь результат сам, не полагаясь на слова: `chatkeeper collect status`.
Если режим не включён, подключения не будет - попроси повторить, показав,
что пункт называется именно **Secretary Mode**, а не Business Mode.

## Шаг 4. Подключить бота к личным чатам

**Только на компьютере.** На телефоне этот пункт просит купить Premium - это недоработка
интерфейса, а не настоящее требование: подписка для подключения бота не нужна.
Если человек сидит только с телефона, объясни, что нужен телеграм на компьютере
именно для этого шага, один раз.

Скажи человеку:

> Открой телеграм на компьютере: Настройки - **Telegram для бизнеса** - **Чат-боты**.
> Впиши адрес нашего бота. Дальше телеграм предложит выдать боту права -
> **не выдавай ни одного**, просто подтверди.

Про права объясни своими словами, коротко:

> Права нужны ботам, которые отвечают за тебя. Наш только читает. Если выдать право
> отвечать - на его сообщениях будет видна пометка, что писал не человек. Если выдать
> право помечать прочитанным - собеседник увидит, что сообщения читаются сами собой.
> Читать переписку бот может и без всяких прав, так что выдавать нечего.

Проверь: `chatkeeper collect status`. Должно быть сказано, что подключение работает.
Если нет - попроси написать себе что-нибудь с другого аккаунта и проверь снова:
подключение становится видно после первого же события, иногда с задержкой в несколько
секунд.

## Шаг 5. Разовая выгрузка: неделя переписки и карта чатов

Без этого шага продукт в первый день пуст и нем: бот приносит только то, что пришло
после подключения, истории у него нет и быть не может. Плюс без выгрузки нельзя
показать человеку список его чатов - боту список диалогов недоступен.

Объясни, зачем это, и подчеркни, что делается **один раз**:

> Чтобы система заработала сразу, а не через неделю, нужна разовая выгрузка переписки.
> Это встроенная кнопка телеграма, всё происходит у тебя на компьютере, никуда
> не отправляется. Делается один раз, дальше бот работает сам.
>
> Телеграм на компьютере: Настройки - Продвинутые настройки - Экспорт данных.
> Формат обязательно **JSON**, период - последняя неделя, галочки с фото и видео
> лучше снять, иначе выгрузка будет тяжёлой. Когда закончится, пришли мне путь
> к папке, которую телеграм создал.

Получив путь:

1. `chatkeeper history chats <путь>` - список чатов, **без единой строки переписки**.
2. Покажи список человеческим текстом, сгруппировав по типу (личные и группы)
   и по свежести. Id и технические поля не показывай.
3. Задай вопросы про чаты - это шаги 5.1 и 5.2 ниже.
4. `chatkeeper history import <путь> 7` - влить неделю переписки.
5. Скажи, сколько чатов и сообщений взято.

### 5.1. Какие чаты рабочие

> Вот твои чаты за неделю. Скажи своими словами, какие из них рабочие и по каким
> проектам. Это нужно, чтобы в сводке рабочее не путалось с личным.

Ответ запиши: `chatkeeper setup chats-keep <id через запятую>` для тех, что остаются
в разборе. Названия проектов держи в голове разбора - они пригодятся при группировке
сводки, но выдумывать проекты, которых человек не называл, нельзя.

### 5.2. Куда не заглядывать никогда

> А есть чаты, в которые не стоит заглядывать вообще никогда - личное, семья, врачи,
> деньги? Их я закрою наглухо: они не будут читаться ни при каких обстоятельствах.

Каждый названный чат - `chatkeeper setup stop-add <id>`. Стоп-список сильнее всего
остального: такой чат не попадает даже в буфер на диске.

Подтверди словами: сколько чатов в разборе и сколько закрыто наглухо. Скажи, что
список можно менять в любой момент словами, это не переустановка.

**Про группы скажи честно, не пряча:** из выгрузки приедут и группы, но только
за прошедшую неделю. Дальше группы не отслеживаются - для этого пришлось бы добавить
бота в каждую группу, а его там видели бы все участники.

## Шаг 6. Три вопроса про то, как система будет себя вести

Задавай по одному, не списком: человек отвечает словами, а не заполняет анкету.

**6.1. Во сколько присылать сводку?** По умолчанию в 9 утра.

1. `chatkeeper setup schedule 09:00`
2. Создай локальную задачу по расписанию в Claude Code (Desktop scheduled task)
   на это время с инструкцией: «Выполни скилл chatkeeper: разбери переписку
   за прошедшие сутки и отправь утреннюю сводку».
3. Объясни три ограничения, без них человек решит, что всё сломалось:
   - сводка приходит, только когда компьютер включён и Claude Code открыт;
   - если компьютер спал, сводка придёт один раз при пробуждении, а не за все
     пропущенные дни;
   - **если компьютер был выключен дольше суток, часть сообщений не придёт никогда.**
     Телеграм хранит недоставленное 24 часа. Система об этом честно предупредит
     в сводке отдельной строкой, но лучше сказать заранее.

**6.2. Класть ли встречи в календарь?** «Когда в переписке появится созвон с временем,
я могу присылать файл, который одним нажатием ставит его в календарь с напоминанием.
Нужно?» Если нет - файлы встреч не отправляй, договорённость всё равно попадёт в сводку.

**6.3. Расшифровывать ли голосовые?** Проверь сначала сам: `chatkeeper voice check`.
Если расшифровка доступна - «Голосовые сообщения я могу переводить в текст прямо
на твоём компьютере, наружу они не уходят. Включаем?» Если недоступна - не спрашивай
вовсе, а скажи, что голосовые будут помечаться в сводке как голосовые.

Итого человек отвечает на шесть вопросов за всю установку: согласие на разбор
переписки, рабочие чаты, запретные чаты, время сводки, календарь, голосовые.
Больше ничего спрашивать не нужно - остальное система выясняет сама.

## Шаг 7. Первый разбор прямо сейчас

Не отпускай человека, не показав результат - иначе он не поверит, что всё работает.

1. `chatkeeper setup check` - убедись, что всё на месте.
2. Проведи полный разбор по `SKILL.md`. Неделя из выгрузки уже влита на шаге 5,
   поэтому разбирать есть что и первая сводка выйдет содержательной.
3. Скажи, что сводка ушла в бота, и попроси проверить.

Если человек пропустил выгрузку, предупреди честно: первые дни сводка будет бедной,
потому что бот видит переписку только с момента подключения. Выгрузку можно сделать
и позже, командой `chatkeeper history import <путь> 7`.

## Если что-то пошло не так

Никогда не показывай человеку текст ошибки. Переведи на человеческий и предложи
одно конкретное действие.

| Что случилось | Что сказать |
|---|---|
| Нет интернета или VPN | «Телеграм сейчас недоступен. Включи VPN и скажи, когда готово» |
| Неверный токен бота | «Токен не подошёл. Пришли его ещё раз целиком, вместе с цифрами до двоеточия» |
| Бот не получил Start | «Открой чат с ботом и нажми кнопку Start внизу» |
| Подключение не видно | «Проверь на компьютере: Настройки - Telegram для бизнеса - Чат-боты. Наш бот должен быть в списке» |
| В телефоне просят Premium | «Этот пункт нужно нажать именно на компьютере, на телефоне телеграм ошибочно просит подписку» |
| Сообщений нет совсем | «Напиши себе с другого аккаунта и скажи мне - проверю ещё раз» |
| `chatkeeper` не найден | Плагин выключен: `/plugin` и включить, либо `/reload-plugins` |
| Нет python | Ставь `uv`, человеку скажи «доустанавливаю недостающее» |

## После установки

Скажи пять вещей и закончи:

- сводка будет приходить каждое утро в назначенное время;
- можно попросить разбор в любой момент: «разбери чаты сейчас»;
- если в сводку попало лишнее или чего-то не хватает - сказать словами,
  настройки поправятся;
- система видит только личные диалоги и только с момента установки;
- **переписка оседает в истории Claude Code**, и её можно вычистить в любой момент
  словами «почисти историю разборов» - это команда `chatkeeper setup forget`,
  сначала покажет что нашлось, удалит только после подтверждения.
