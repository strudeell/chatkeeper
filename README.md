# Chatkeeper

Плагин для Claude Code. Читает вашу переписку в телеграме, вытаскивает договорённости
и встречи и каждое утро присылает одно сообщение: что сегодня сделать, кому что обещано,
какие созвоны и что стоит начать заранее, чтобы успеть к сроку.

Смысл один - **не открывать двадцать чатов по утрам**, чтобы вспомнить, что вы кому обещали.

## Что он делает

- Находит в переписке обещания: ваши и вам.
- Собирает встречи и присылает их файлом, который открывается в календаре.
- Помнит, что закрыто: сказали «отправил» - задача исчезает из завтрашней сводки.
- Предупреждает заранее: если работы на три дня, а срок через два, скажет об этом сегодня.
- Показывает просроченное и вопросы, на которые вам не ответили.

## Установка

В Claude Code три команды, по одной:

```
/plugin marketplace add strudeell/chatkeeper
/plugin install chatkeeper@chatkeeper
/chatkeeper:install
```

Последняя запускает установку: дальше Claude проведёт вас сам, задавая вопросы
по одному. Отвечать надо словами, как в обычной переписке.

Что понадобится сделать руками, кнопками в телеграме:

1. завести бота у `@BotFather` и включить ему **Secretary Mode**;
2. подключить бота к личным чатам: **на компьютере** Настройки → Telegram для бизнеса →
   Чат-боты. Прав боту выдавать не нужно ни одного.

Ключи разработчика (`api_id`) и платная подписка Telegram Premium **не требуются**.
Терминал открывать не нужно, файлы править не нужно.

> На телефоне пункт «Чат-боты» ошибочно просит купить Premium. Это недоработка
> приложения: по документации Telegram подключение бота подписки не требует.
> На компьютере всё открывается.

## Обновления

Новые версии не приезжают сами. Чтобы забрать свежую:

```
/plugin marketplace update chatkeeper
```

Дальше обновите плагин через меню `/plugin`. Настройки, ключ бота и память
об обещаниях при обновлении не теряются: они лежат отдельно от папки плагина.

## Что он видит и чего не видит

| | |
|---|---|
| Личные диалоги | Видит, автоматически |
| Рабочие группы | **Не видит.** Бота пришлось бы добавить в каждую группу, и его увидели бы все участники |
| История переписки | **Не видит.** Только то, что пришло после подключения. Первые дни сводка будет бедной |
| Каналы | Не видит |

Если компьютер был выключен дольше суток, часть сообщений не придёт никогда: Telegram
хранит недоставленное 24 часа. Система честно предупредит об этом строкой в сводке.

## ⚠️ Что важно знать до установки

**Собеседники о системе не узнают.** Бот только читает: он никогда не пишет и не помечает
сообщения прочитанными, поэтому в чатах не появляется никаких признаков автоматизации.
Но согласия эти люди не давали, и решение отдавать их слова на разбор - ваше.
Стоп-список для семьи, врачей и всего личного существует именно поэтому: такой чат
не попадает даже во временный файл на диске.

**Про блокировки.** Работа идёт через штатные механизмы Telegram - Bot API и подключение
бота в настройках. Аккаунт при этом ничего не автоматизирует и ничем не рискует.
Правила для разработчиков ботов требуют вашего явного разрешения на передачу содержимого
сообщений сторонним сервисам - установка его и спрашивает, первым же вопросом.

Отдельно: путь через ключи разработчика (`api_id`) и вход под живым аккаунтом в этом
плагине **не используется по умолчанию** именно потому, что он единственный несёт
реальный риск для аккаунта.

## Приватность: что важно понимать до установки

Здесь без прикрас, потому что речь о чужой переписке тоже.

**Переписка уходит в Anthropic.** Разбор делает языковая модель Claude, а она работает
не на вашем компьютере. Содержимое отобранных чатов за сутки отправляется на разбор -
иначе продукт невозможен в принципе.

**Прочитанное остаётся в истории Claude Code.** Claude Code сохраняет содержимое сессий
в файлы на вашем компьютере (`~/.claude/projects/`). Рабочая выгрузка переписки удаляется
сразу после разбора, но её копия остаётся в истории сессии и после этого. Навсегда,
пока вы не удалите её сами.

Для этого есть команда. Показать, где осела переписка и сколько её:

```
chatkeeper setup forget
```

Удалить найденное:

```
chatkeeper setup forget --confirm
```

Удаляется файл истории целиком, вместе с остальной работой в тех же сессиях -
команда предупредит об этом перед удалением.

**Что остаётся только у вас:** ключ бота, настройки, память об обещаниях, расшифровки
голосовых - всё лежит на вашем компьютере и никуда, кроме модели, не отправляется.
Никаких посредников между Telegram и вашим компьютером в схеме нет.

**Голосовые расшифровываются локально**, если на компьютере есть чем. Файл скачивается,
распознаётся и тут же удаляется.

## Ключи

Настоящие ключи живут в файле `.env` в папке данных плагина, а не в этом репозитории:
`~/.claude/plugins/data/chatkeeper*/.env`. В поставке лежит только образец
`.env.example` - имена переменных без значений. Файл `.env` внесён в `.gitignore`
и в репозиторий не попадает никогда.

Папка данных отделена от папки плагина намеренно: при обновлении плагин заменяется
целиком, и всё рабочее - ключи, память об обещаниях, окружение - обновление переживает.

**Про собеседников.** В ваших чатах участвуют люди, которые согласия на разбор не давали.
Стоп-список - для семьи, врачей и всего личного - существует именно поэтому.
Пользуйтесь им щедро.

## Требования

- Claude Code (десктоп) на Windows или macOS.
  На Linux не работает: там нет локальных задач по расписанию.
- Python (если его нет, установщик поставит `uv` сам).
- Компьютер включён и Claude Code открыт в то время, когда должна прийти сводка.
  Если компьютер спал, сводка придёт один раз при пробуждении.

## Как это устроено

| Часть | Что делает |
|---|---|
| `scripts/collect.py` | вход по QR, отбор чатов по метаданным, забор новых сообщений |
| `scripts/digest.py` | память об обещаниях и сборка утренней сводки |
| `scripts/send.py` | доставка через бота, файлы встреч `.ics` |
| `scripts/setup.py` | установка и настройка |
| `SKILL.md` | правила, по которым Claude вытаскивает договорённости из живой речи |

Чаты отбираются **без чтения сообщений**: по типу чата, папкам телеграма, архиву,
отключённым уведомлениям и дате последней активности. Каналы, боты и мёртвые чаты
отсеиваются сразу, и только оставшееся показывается вам на подтверждение.

Данные лежат в `~/.claude/plugins/data/chatkeeper*/` и переживают обновления плагина.
